# Unity Git Practice — Crystal Lab

Практическая работа по дисциплине «Технологии повышения эффективности разработки игровых решений».

Мини-игра: соберите три кристалла на платформе. WASD / стрелки — движение, R — перезапуск. Кнопка Restart также перезапускает уровень.

## Запуск
1. Unity Hub → Add project from disk → выбрать эту папку.
2. Открыть в установленной Unity 6000.6.5f1.
3. Открыть Assets/Scenes/Level.unity и нажать Play.
4. В Console проверить сообщение `[LevelValidator] Scene valid. Pickups: 3`.

В лекции используется 6000.3.16f1; работа выполнена на установленной 6000.6.5f1. Дополнительные ассеты и платные пакеты не требуются.

## Git
- main: базовый проект, затем результаты двух PR.
- feature/enemies: усиление игрока и ускорение вращения кристаллов.
- feature/ui: альтернативный баланс тех же полей и повышение награды.
- Сцены — Force Text, meta-файлы — Visible Meta Files.
- Assets, Packages, ProjectSettings хранятся в Git; Library, Temp, Logs исключены.

PDF для защиты будет создан отдельно после подтверждения готовности практики.
